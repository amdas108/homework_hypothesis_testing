# Проверка статистических гипотез

## Как выполнить и сдать

Решения пишите в `homework_hypothesis_testing.qmd`: под заданиями оставлены места для кода и текстовых ответов. Исходные данные находятся в файле `data/abalone.csv`. Физический масштаб восстановлен умножением непрерывных признаков опубликованного набора [UCI Abalone](https://archive.ics.uci.edu/dataset/1/abalone) на 200. Столбцы `Sex` и `Rings` сохранены без изменений.

1. Откройте папку задания в Positron (`File → Open Folder`). Файл `homework_hypothesis_testing.qmd` и папка `data` должны находиться в корне открытого проекта.
2. Заполните qmd-файл кодом и ответами, сохраняя структуру задания. Требования к содержанию и оформлению отчёта приведены в самом задании.
3. Используйте относительные пути от корня проекта, например `data/abalone.csv`. Путей вида `C:/Users/…` или `/Users/…` в работе быть не должно.
4. Отрендерите заполненный файл в html: кнопкой Preview в Positron или командой `quarto render homework_hypothesis_testing.qmd`. Рядом появится `homework_hypothesis_testing.html`.
5. Перед сдачей убедитесь, что qmd выполняется целиком без ошибок и без объектов, созданных вручную вне отчёта. html должен быть получен из последней версии сдаваемого qmd и содержать все результаты и ответы.
6. Создайте папку `homework_hypothesis_testing` в своём приватном репозитории GitHub и загрузите в неё qmd, html и папку `data`. Сохраните изначальную структуру папки. Рекомендуем использовать уже созданный репозиторий, где будут храниться все ваши домашние задания.
7. Пригласите в репозиторий **GitHub-аккаунт проверки**: [bicheck2013](https://github.com/bicheck2013), если этого еще не сделали.
8. Чтобы сдать задание, **приложите ссылку на папку `homework_hypothesis_testing` в вашем репозитории GitHub**. По ссылке должны быть доступны оба файла отчёта и данные.
